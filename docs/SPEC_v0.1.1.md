## 重要要件（抜粋）
- ループ動画に選択肢を重ねる（必須）
- ループの柔軟運用：
  - A,A,A,...
  - AB,AB,...
  - ACBABC,ACBABC,...（任意パターン）
- 選択確定でループ中でも次セグメントへ切替
- 切替時トランジション（必須）
- Webストリーミング配信を主対象（Ren’Py Web/HTML5）
- ローカル（Windows）は同一コンテンツから生成しやすい設計
