# Validation (縦切り成功判定観点)

Date: 2026-01-01

縦切り（Vertical Slice）が「動いた」と判定するための観点を定義します。

---

## 判定基準

### ✅ 全体

| 項目 | 判定観点 |
|------|---------|
| Web起動 | `http://localhost:...` でRen'PyのUI（テキスト・選択肢）が表示される |
| 動画再生 | UIの背後で動画が再生されている（黒画面ではない） |
| 音声 | プロトタイプではミュート前提（音が出なくても正常） |

---

## セグメント別判定

### seg_loop_A（Aループ＋常時選択肢）

| 項目 | 判定観点 |
|------|---------|
| ループ | Aクリップが無限ループ再生される |
| 選択肢表示 | 「ABループへ」「ACBABCループへ」が **常時表示** |
| 選択クリック | 選択肢をクリックすると次のセグメントへ遷移 |
| トランジション | 遷移時に crossfade（0.25秒）が適用される |

### seg_loop_AB（ABループ＋boundary切替）

| 項目 | 判定観点 |
|------|---------|
| パターン | A → B → A → B... の順でループ |
| クリップ間遷移 | AからBへの切替時に dissolve（0.12秒）が見える |
| 選択肢表示 | 再生開始0.8秒後に選択肢表示（`timed` モード） |
| boundary切替 | 選択後、**現在のクリップ終端** で次セグメントへ遷移（即座ではない） |
| トランジション | セグメント遷移時に crossfade が適用される |

### seg_loop_ACBABC（任意パターンループ＋immediate切替）

| 項目 | 判定観点 |
|------|---------|
| パターン | A → C → B → A → B → C の6クリップ順でループ |
| 選択肢表示 | 常時表示 |
| immediate切替 | 選択後、**即座に** 次セグメントへ遷移 |
| トランジション | セグメント遷移時に fade（0.2秒、黒への遷移）が適用される |

---

## トランジション確認

| 種類 | 動作 | 確認方法 |
|------|------|---------|
| crossfade | 旧動画がフェードアウトしながら新動画がフェードイン | 一瞬両方の映像が重なって見える |
| fade | 黒画面を経由して遷移 | 画面が一度黒くなってから新動画開始 |
| dissolve | クリップ間の滑らかな遷移 | クリップ切替時に硬い切り替えではなく滑らかに混ざる |
| none | 即座に切り替え | 遷移エフェクトなし |

---

## エラー判定

以下が発生した場合は **失敗** として対処が必要:

| 症状 | 原因候補 |
|------|---------|
| 動画が見えない（黒画面） | 動画ファイル未配置 / パス誤り / パッチ未適用 |
| UIが見えない | Ren'Py canvas の z-index 問題 / CSS未適用 |
| 選択肢が反応しない | Ren'Py側のscreen定義問題 |
| Consoleに `clip_load_failed` | 動画形式非対応 / ファイル不存在 |
| CORSエラー | `file://` アクセス（Webサーバ経由必須） |

---

## チェックリスト

動作確認時に使用:

- [ ] seg_loop_A でAがループ再生される
- [ ] seg_loop_A の選択肢が常時表示される
- [ ] seg_loop_A から seg_loop_AB へ遷移できる
- [ ] seg_loop_AB でA→B→A→B...の順にループする
- [ ] seg_loop_AB のクリップ間でdissolveが見える
- [ ] seg_loop_AB で選択後、クリップ終端まで待ってから遷移する
- [ ] seg_loop_ACBABC でA→C→B→A→B→Cの順にループする
- [ ] seg_loop_ACBABC で選択後、即座に遷移する（fade適用）
- [ ] 全てのセグメント遷移でトランジションが適用される
